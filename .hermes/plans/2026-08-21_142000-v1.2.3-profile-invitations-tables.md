# Bodapp v1.2.3 — Profile Panel, Invitation Fixes, Tables Redesign

> **Approach:** Sequential implementation, one task at a time. Each task has tsc + test verification before commit.

**Goal:** 5 grouped changes —
1. Profile panel for couple settings (names, email, venue)
